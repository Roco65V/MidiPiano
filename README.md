# 🎹 MIDIPiano

MIDIPiano 是一个纯浏览器的网页钢琴 / MIDI 演奏器：电脑键盘、屏幕琴键、外接 MIDI 设备三种演奏方式，
128 种 GM 音色，MIDI 文件播放，并支持 Docker / Windows exe 一键部署。

MIDIPiano is a pure browser-based web piano / MIDI player with keyboard, on-screen keys and MIDI device input,
128 GM instruments, MIDI file playback, and Docker / Windows exe deployment.
